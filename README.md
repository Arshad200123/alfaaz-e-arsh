# ALFAAZ E ARSH

Flutter MVP starter for the ALFAAZ E ARSH poetry app.

## MVP screens
- Splash
- Home
- Search
- Poets
- Poet detail
- Poem detail
- Upload
- Profile
- Login / Sign up

## Supabase
The project is structured so Supabase credentials can be supplied through `--dart-define` when the Flutter app is run.

Example:
flutter run --dart-define=SUPABASE_URL=YOUR_URL --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_KEY
